## 1. Structured Reasoning — ICLR 2026

**Published title:** Structured Reasoning for LLMs: A Unified Framework for Efficiency and Explainability

**Authors:** Yubo Dong, Hehe Fan, Linchao Zhu, Yi Yang

**Suggested headline:** Give LLM reasoning a step-level structure.

**Short description:** Structured Reasoning labels cognitive operations and analyzes relationships between reasoning steps. MaxFlow and LCS rewards guide optimization toward efficient, stable reasoning. The paper studies 1.5B and 7B models; readers can explore an interactive analyzer and a public tagged dataset.

**Audience:** Researchers in reasoning, process supervision, reinforcement learning for LLMs, efficient inference, and interpretability.

**Keywords:** structured reasoning; cognitive step tags; reasoning graphs; MaxFlow reward; LCS reward; GRPO; efficient reasoning; explainability.

**Links:**
- [ICLR 2026 paper and citation](https://proceedings.iclr.cc/paper_files/paper/2026/hash/ad5b3f324b24c17cdc2f3712298c76bd-Abstract-Conference.html)
- [Project and interactive demo](https://cnsdqd-dyb.github.io/Enhancing-Large-Language-Models-through-Structured-Reasoning/)
- [Repository and release roadmap](https://github.com/cnsdqd-dyb/Enhancing-Large-Language-Models-through-Structured-Reasoning)
- [Public dataset](https://huggingface.co/datasets/FreeFrank/Structured-Reasoning)
- [Accessible project note](https://cnsdqd-dyb.github.io/workshare/2025/11/24/StructuredReasoning.html)

**Resource status:** Public paper, figures, interactive demo, and 516-example dataset with 23 cognitive step types. Training code and model checkpoints are planned. The released dataset is not asserted to be the exact experimental training corpus.

## 2. VillagerAgent — ACL 2024

**Published title:** VillagerAgent: A Graph-Based Multi-Agent Framework for Coordinating Complex Task Dependencies in Minecraft

**Authors:** Yubo Dong, Xukun Zhu, Zhengzhe Pan, Linchao Zhu, Yi Yang

**Suggested headline:** Test teamwork where task dependencies matter.

**Short description:** VillagerAgent coordinates agent work through a task dependency graph. VillagerBench supplies Minecraft collaboration tasks involving construction, cooking, and escape challenges, letting researchers investigate task decomposition, coordination, and adaptation to spatial and temporal constraints.

**Audience:** Researchers in multi-agent systems, embodied agents, task planning, agent benchmarks, and cooperative decision-making.

**Keywords:** multi-agent collaboration; VillagerBench; Minecraft; task dependencies; task decomposition; DAG planning; embodied agents.

**Links:**
- [Published paper and official citation](https://aclanthology.org/2024.findings-acl.964/)
- [Code and benchmark](https://github.com/cnsdqd-dyb/VillagerAgent-Minecraft-multiagent-framework)
- [Project note and demonstrations](https://cnsdqd-dyb.github.io/workshare/2024/04/01/VillagerAgent.html)

## 3. Hi-Lo Prune — CVPR 2026

**Published title:** Hi-Lo Prune: Look at What You'll Lose before Pruning with Hierarchical Token Selection

**Authors:** Zixun Sun, Yubo Dong, Hehe Fan, Yi Yang

**Suggested headline:** Keep the information before reducing visual tokens.

**Short description:** Hi-Lo Prune is a training-free approach to visual token pruning. It selects tokens hierarchically, transfers information from pruning candidates to retained tokens through attention, and then removes candidates to reduce later computation. The paper evaluates the method on Qwen vision-language models.

**Audience:** Researchers in vision-language models, multimodal inference, token pruning, and model efficiency.

**Keywords:** visual token pruning; multimodal language models; training-free inference; hierarchical token selection; attention-guided token merging; efficient VLMs.

**Links:**
- [CVPR paper and official citation](https://openaccess.thecvf.com/content/CVPR2026/html/Sun_Hi-Lo_Prune_Look_at_What_Youll_Lose_before_Pruning_with_CVPR_2026_paper.html)
- [Author repository](https://github.com/sealost/Hi-Lo_Prune)
- [Project note](https://cnsdqd-dyb.github.io/workshare/2026/06/01/HiLoPrune.html)

**Resource status:** Public paper and supplementary material. Check the author repository for current implementation availability before advertising released code.
